# Cart Total Calculator

A JavaScript exercise that calculates a cart subtotal from item prices and quantities, then applies a discount and tax to produce a total.

## Usage

Open `index.html` in a web browser and open the developer tools console to see the example results. Edit the items and calls in `script.js` to try other values. No installation is required.

1. Clone the repository:

```bash
git clone https://github.com/Gabzx1/Roadmap.sh-Projects.git
```
