# Grade Report Generator

A JavaScript exercise that generates a student report with a letter grade, pass status, and feedback. Scores of 60 or higher pass.

## Usage

Open `index.html` in a web browser and open the developer tools console to see the example results. Edit the calls in `script.js` to try other names and scores. No installation is required.

1. Clone the repository:

```bash
git clone https://github.com/Gabzx1/Roadmap.sh-Projects.git
```
