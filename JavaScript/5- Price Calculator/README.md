# Price Calculator

A JavaScript exercise that calculates a discount, applies tax to the discounted price, and returns a price summary.

## Usage

Open `index.html` in a web browser and open the developer tools console to see the example results. Edit the calls in `script.js` to try other values. No installation is required.

1. Clone the repository:

```bash
git clone https://github.com/Gabzx1/Roadmap.sh-Projects.git
```
